# Zeidyen.github.io

Personal website of **Dr Abdulzeid Yen Anafo**, Lecturer in Mathematics and
Statistics at the University of Mines and Technology, Tarkwa.

Live at <https://zeidyen.github.io/>

## Layout

| Path | What it is |
|---|---|
| `index.html` | Front page — about, skills, work experience, contact |
| `software.html` | Publications |
| `webdev.html` | Machine learning projects |
| `cp.html` | Programming profile |
| `teaching/` | **Course materials for students** — see `teaching/README.md` |

## Course materials

Everything students see lives in `teaching/data/content.js`. That is the only
file to edit when posting lecture notes, assignments or papers; the folder's own
README explains how. PDFs go in `teaching/files/`.
